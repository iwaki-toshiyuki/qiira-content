# はじめに
私用で以前読んだ書籍を再読したのですが、**再読には意外と価値がある**と感じたので、
今回の記事を書くことにしました。

# なぜ再読に価値があると感じたのか

### 以前読んだときと視点が変わった気がする
今回読んだ書籍は数年ぶりに読んだのですが、
以前読んだときにはなかった視点を得たような気がしました。

おそらく、**同じ情報でもそのときの自分の知識や経験によって、
得られるものが変わる**からなのかなと思っています。

### 内容を忘れているので思い出すことができた
数年ぶりに読んだので、当然ながら忘れている内容も多くありました。
再読することで以前学んだ内容を思い出すことができ、
改めて知見を得たように感じました。

一度読んだだけでは、そのときは理解したつもりでも、
時間が経つにつれて内容を忘れてしまうことがあります。

**再読することで忘れていた内容を思い出すだけでなく、
以前得た知識をもう一度整理する機会にもなりました。**

### 以前は理解できなかった内容が理解できる
初めて読んだときには理解できなかった内容でも、
知識や経験を積んだ状態で再読すると理解できることがあります。

以前は何となく読み流していた部分が、
**再読したときには「こういう意味だったのか」と理解できることも、
再読の価値の一つだと思います。**

### 自分自身の変化に気づくことができる
同じ本を読んでいるにもかかわらず、
以前とは違う部分が印象に残ることがあります。

本の内容自体は変わっていないため、
受け取り方が変わったということは、
**自分の知識や経験、考え方が変化したとも考えられます。**

再読には、本の内容を振り返るだけでなく、
以前の自分と現在の自分の違いを確認できる価値もあると感じました。

# どれくらい期間を空けるべきなのか
あくまで個人的な意見ですが、
**最低でも半年以上空けた方が良いのではないかと感じています。**

半年も空けると、自分の知識や経験にも色々な変化が起きていると思うので、
再読するには良いタイミングなのではないかと思います。

ただ、理想を言えば一年以上空けた方が、
以前とは違った気づきを得やすくなるのではないかと感じています。

# おわりに
今回の記事は「再読は意外と価値があるな」と率直に思ったので、
記事にまとめてみました。

この記事が、少しでも参考になれば幸いです。
